# Yifan Wang — Personal Homepage

A no-framework static portfolio designed for GitHub Pages.

## Deploy

1. Create a GitHub repository (for example `yourusername.github.io`).
2. Upload all files in this folder to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Your site will be available at `https://yourusername.github.io/`.

## Replace placeholders

- `assets/avatar-placeholder.svg` → your portrait.
- `assets/background-placeholder.svg` → your preferred background image (you can also use JPG/PNG and update `styles.css`).
- `assets/photo-placeholder-1.svg`, `2.svg`, `3.svg` → photography / hobby / research images.
- `assets/cat-placeholder.svg` → your cat photo.
- In `index.html`, replace `hello@example.com`, `yourusername`, and any biographical text you want to change.

## Recommended photo sizes

- Hero portrait: vertical 4:5, at least 1200×1500.
- Background: horizontal 16:9 or wider, at least 2000 px wide.
- Hobby photos: vertical 4:5 works best.
- Cat photo: vertical 4:5.

No build step is required.
